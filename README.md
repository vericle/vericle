## Featured Projects

### [🦞 HeyClaw](https://github.com/vericle/heyclaw)

**GPT Live-style voice AI running directly in your terminal, with a compact Python core of roughly 1,500 lines.**

A headless, real-time voice assistant powered by ElevenLabs, Gemini, Mem0, and MCP tools. It combines natural voice conversations, persistent memory, extensible tools, and local wake-word detection without a bloated UI or a complicated local-model stack.

`Python` • `ElevenLabs` • `Gemini` • `Mem0` • `MCP` • `Voice AI`

[Repository](https://github.com/vericle/heyclaw) • [Latest release](https://github.com/vericle/heyclaw/releases/latest)

### [IntellyWeave](https://github.com/vericle/intellyweave)

AI-powered OSINT platform for intelligence analysts, historical researchers, and investigative journalists.

Built with FastAPI, Next.js, Weaviate, DSPy, GLiNER entity extraction, and Mapbox 3D geospatial visualization.

**Origin:** built to investigate the Cold War fate of my aunt Ingeborg Loucek, a U.S. Army Counter Intelligence Corps agent who disappeared in Vienna in 1950.
